# Play-test checklist

## Setup (once)
1. Install Godot 4.4.1 (standard build) from godotengine.org.
2. Clone the repo, open Godot, Import → select `project.godot`.
3. Press F5 (Run Project).

## M1 — grey-box Pine Town
- [ ] Game opens on Pine Town with the HUD showing "Pine Town" top-left.
- [ ] WASD moves the red capsule, Shift runs, mouse orbits the camera, wheel zooms, Esc frees the mouse.
- [ ] Walk north into the player's house door mat: toast says "Door: house_player".
- [ ] Press E facing the sign by the spawn: toast shows the Pine Town sign text.
- [ ] Walk east along the main path through the tall grass patch: toast says "Entered tall grass (route 101)".
- [ ] Reach the "→ Route 101" marker: toast says route exit not built yet.
- [ ] Trees block movement; you cannot walk off the map edge.
- [ ] F3 shows FPS. Report the FPS number and your GPU.

Report with one screenshot of the town from the spawn point and any item that failed.
